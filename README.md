# shiuri-APP
# 栞 Shiori GLOBAL 🌿
### The AI-Powered Circular Learning Network for Students

> **More Books. Bigger Dreams.**
>
> Buy • Sell • Donate • Swap • Discover — and give every book a second life.

Shiori GLOBAL is a modern circular learning platform designed for students to discover, exchange, donate, and reuse educational resources.

The platform combines a **student-focused textbook marketplace, AI book scanning, smart exchange, real-time communication, trust & safety, and community impact tracking** into one ecosystem.

---

## ✨ Vision

Millions of educational books are left unused after a student completes a course.

Shiori GLOBAL aims to create a circular learning ecosystem where students can:

- 📚 Buy affordable textbooks
- 🔄 Exchange books with other students
- 🎁 Donate unused books
- 💰 Sell books they no longer need
- 🤖 Identify books using AI
- 💬 Connect with verified book owners
- 🌱 Track environmental and social impact

### Core Idea

**One student's old book → another student's learning opportunity.**

## 🤖 AI Book Scanner

Shiori GLOBAL includes an AI-powered book detection system.

Users can upload or scan a book cover and automatically detect:

- Book Title
- Author
- Class
- Subject
- Edition
- Condition
- Publisher
